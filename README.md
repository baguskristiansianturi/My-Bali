# My Bali

**An independent Bali-focused product by Bagus Kristian Sianturi.**

My Bali is being shaped as a connected platform for discovering Bali, planning journeys, connecting with genuine local providers, booking supported services, and keeping or sharing travel experiences.

- Product owner: Bagus Kristian Sianturi
- Portfolio relationship: Bagusin portfolio; My Bali remains an independent product.
- Geographic identity: Bali.
- Current stage: concept development and product discovery. The public website is an introductory profile, not a live booking platform.

## Repository structure

- `index.html` — public My Bali product/company profile (GitHub Pages).
- `MASTER/` — evolving product vision, concept, business model, principles, and roadmap.
- `MASTER/PRODUCTS/MY-BALI/` — detailed product concept documents.
- `CHANGE-REGISTER.md` — meaningful documentation and product-direction changes.

## Important status rules

Ideas, examples, assumptions, proposals, approved decisions, and validation tasks must remain clearly distinguished. A discussion example is not automatically a requirement. Material product and policy decisions require founder confirmation.

No production application, booking, payment, provider onboarding, or mobile app is available merely because this repository exists.
